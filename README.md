# AI Workplace Productivity Assistant

> **Work smarter. Communicate better. Get more done with AI.**

## 📌 Project Overview

**AI Workplace Productivity Assistant** is a modern, responsive AI-powered productivity web application designed to help professionals automate and simplify common workplace tasks.

The application provides AI-driven tools for generating professional emails, summarising meeting notes, extracting actionable information, and assisting users with everyday workplace questions and communication.

The project focuses on creating a clean, professional SaaS-style user experience while demonstrating practical applications of generative AI in the workplace.

---

## ✨ Features Implemented

### 📧 Smart Email Generator

Generate professional workplace emails based on the user's specific requirements.

**Features include:**

* Email purpose selection
* Recipient input
* Key points and instructions
* Multiple writing tones:

  * Formal
  * Friendly
  * Persuasive
* AI-generated subject lines and email content
* Editable AI-generated output
* Copy, regenerate, edit and clear actions

### 📝 Meeting Notes Summarizer

Transform lengthy meeting notes into concise, actionable information using AI.

**The tool extracts:**

* Meeting summary
* Key discussion points
* Important decisions
* Action items
* Responsible owners
* Deadlines

AI-generated summaries can be edited, copied, regenerated or cleared.

### 🤖 AI Workplace Assistant

An interactive AI chatbot designed to assist with everyday workplace tasks.

Users can:

* Ask workplace-related questions
* Improve professional messages
* Generate project updates
* Prepare for meetings
* Brainstorm ideas
* Request writing assistance
* Enter custom prompts

Responses are dynamically generated by AI based on the user's actual input.

### 📊 Modern Dashboard

The application includes a professional SaaS-style dashboard with:

* Sidebar navigation
* Feature cards
* Clear call-to-action buttons
* Responsive layouts
* Loading and interaction states
* Clean visual hierarchy

### ⚙️ Settings

Users can customise basic preferences, including:

* Default email tone
* AI response length
* Professional writing style

### 🕒 Recent Activity

Displays activity performed during the current application session without requiring a database or user account.

### 🛡️ Responsible AI

The application includes a Responsible AI disclaimer reminding users to review AI-generated content and avoid entering confidential, sensitive or personal information.

## 🚀 Setup Instructions

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/ai-workplace-productivity-assistant.git
```

### 2. Navigate to the Project

```bash
cd ai-workplace-productivity-assistant
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure AI Integration

If the project uses an external AI provider, create an environment file:

```bash
.env
```

Add the required AI configuration according to the provider used by the application.

**Do not commit API keys or other sensitive credentials to GitHub.**

### 5. Start the Development Server

```bash
npm run dev
```

The application will be available at the local development address provided by Vite, typically:

```text
http://localhost:5173
```

### 6. Build for Production

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```

## 🔐 Authentication & Backend

This application is designed as a **frontend-first productivity tool**.

* No user registration is required.
* No sign-in is required.
* No user accounts are required.
* No application database is required.
* Recent activity is maintained only during the current session.

AI functionality is designed to generate responses dynamically from user-provided information rather than relying on hardcoded responses.

## 🎯 Project Goals

This project demonstrates how generative AI can be applied to practical workplace productivity tasks.

The main goals were to:

1. Reduce time spent on repetitive workplace communication.
2. Make meeting information easier to understand and act upon.
3. Provide an accessible AI assistant for everyday professional tasks.
4. Demonstrate the integration of AI into a modern SaaS-style web application.
5. Apply responsive UI/UX principles to a real-world productivity solution.

---

## ⚠️ Responsible AI

AI-generated content may contain inaccuracies or omissions. Users should always review and verify AI-generated information before using it for important workplace decisions or communications.

**Do not enter confidential, sensitive, or personal information into the application.**
